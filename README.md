## 디자인

밝은 배경, 파란색 강조, 중앙의 큰 제목, 둥근 상단 메뉴와 상담 버튼, 넉넉한 여백, 흰색 카드, 어두운 하단 상담 영역을 참고했습니다. PC에서는 내용을 나란히 배치하고 모바일에서는 순서대로 읽히도록 구성했습니다. 소비자 반응과 가격표는 원본의 모바일 2열 배치를 유지했습니다.

원본의 14개 본문 섹션, 실제 이미지와 자료, 가격, 법적 안내, 사무소 정보, Tally 상담 주소 및 Meta 이벤트를 유지했습니다. 첫 화면 문구를 특허출원 서비스 중심으로 재구성했습니다. 참고 페이지의 실적 수치·후기·가상 고객사·일반 광고대행 서비스 문구는 도입하지 않았습니다.

## 원본 기준 색상·효과 개선

현재 레이아웃과 밝은 첫 화면은 유지했습니다. 원본처럼 특허 소개·상담·가격·전문가·시장 문제·광고 예시·최종 상담 구간에는 네이비를 적용하고, 설명과 결과 구간은 흰색·연한 블루로 구분했습니다. 진행 과정은 밝은 배경 위 어두운 카드입니다.

블루·레드 강조 문구, 골드 가격과 추천 패키지 테두리, 원본의 밑줄과 소비자 강조점을 살렸습니다. 배경 광원은 고정되어 있고, 문구의 빛 효과는 화면 진입 시 한 번만 재생됩니다. 모션 감소 설정에서는 빛 애니메이션을 끄고 글자를 그대로 표시합니다.

색상과 효과 보정은 src/original-tone.css에 모아 두었습니다.

## 첨부 PDF와 이미지 수정 반영

첨부된 pptCE7E.pdf의 10개 표시를 반영했습니다. 첫 화면 설명의 '완성합니다.'를 '발굴합니다.'로 변경하고, 차별점 설명을 '인체적용시험 · 비포애프터 · 리뷰 · 바이럴광고 · 인플루언서'로 교체했습니다. 운영 안내, 새로운 차별점 문구, 특허출원 기술 제목, 인식 변화 카드의 제목과 결론을 확대하고 굵게 조정했습니다.

상담 단계 3개는 밝은 패널과 블루 번호로 강조하고, 혜택 문구는 큰 흰색 볼드로 변경했습니다. 가격표는 네이비 단품 카드와 골드 추천 카드로 정리하고 건당 가격·총액을 구분했습니다. 실제 가격과 구성은 그대로입니다.

첨부 이미지의 '제품을 바꾼 것이 아니라, 제품을 바라보는 관점을 바꿨습니다' 인용문과 하단 설명도 볼드로 강조했습니다. 글꼴은 로컬 Pretendard이며 설명 문구는 Medium 이상을 사용합니다. '전과정 변리사 직접 진행' 문구도 유지했습니다.

상단은 블루 벡터 심볼·RICH MARKETING·브랜드 설명과 로문 로고의 조합으로 변경했습니다. 로문 로고는 기존 사이트의 2172×724 원본을 사용하며 축소 표시합니다. 브라우저의 색상 반전으로 밝은 헤더에 맞추고, 두 브랜드는 모바일에서도 함께 표시됩니다. 새 로고 이미지는 번들에 포함되어 외부 요청 없이 로드됩니다.

이 수정은 src/review-refinements.css, src/components/BrandLockup.tsx 및 Pricing.tsx에 모았습니다.

## 메인 문구 슬라이드

첫 화면은 기존 문구 → '특허출원 기반 “전략형 IP 마케팅”' → '평범한 제품도, 특허출원으로 특별하게.' 순서로 2초마다 자동 반복됩니다. 각 문구에 사용자가 제공한 설명을 함께 표시하고, 기존 Pretendard·블루 그라데이션·상담 버튼 디자인을 유지했습니다.

사용자 요청에 따라 불릿과 재생 버튼을 제거하고 자동 전환만 적용했습니다. 마우스를 올리거나 버튼에 포커스해도 순환을 유지합니다. 화면 밖이나 비활성 탭에서는 불필요한 타이머를 멈춥니다. 모션 감소 설정에서는 이동 애니메이션만 제거하고 세 문구를 순환합니다.

세 문구가 공유하는 그리드가 가장 긴 문구의 높이를 확보하여, 슬라이드가 바뀌어도 상담 버튼과 아래 섹션이 움직이지 않습니다. 현재 문구만 접근성 트리에 노출되고, 페이지의 h1은 하나로 유지됩니다.

PC·모바일 검사는 자동 순환·모션 감소·320~1440px 화면에서의 높이 유지와 가로 넘침을 포함합니다. 수정 후 배포용 빌드와 관련 검사를 다시 확인했습니다.

## 마지막 문구 정리

차별점 설명은 '인체적용시험 · 비포애프터'와 '리뷰 · 바이럴광고 · 인플루언서'의 두 줄로 고정했습니다. 본문 13개 섹션 안내의 숫자 접두사와 슬래시는 제거하고 안내 문구만 유지했습니다.

## 모바일 카드와 푸터

소비자 반응 카드의 문장을 간결하게 정리하고 모바일 패딩·간격·아이콘 크기를 줄였습니다. 2×2 배치와 18px 볼드 제목, 13px 설명은 유지하며 네 카드의 전체 세로 길이를 줄였습니다. 390px 미리보기에서는 카드 영역이 약 450px로 표시됩니다.

푸터는 검은 배경에 화이트 사무소명, 그레이 상세 정보와 구분선을 사용합니다. 로문 로고의 검은 배경과 자연스럽게 연결되며, 상단과 같은 고해상도 로컬 로고를 재사용합니다. 사무소 정보와 연락처는 유지했습니다.

## 실행과 배포

Node.js 22.12 이상. 처음 실행할 때 npm ci, 개발 서버는 npm run dev, 배포용 빌드는 npm run build입니다. dist 폴더가 배포 결과입니다. npm test로 PC·모바일 검사를 실행할 수 있습니다. Playwright 브라우저가 없다면 npx playwright install chromium으로 설치합니다.

단일 파일 richmarketing-balanced.html은 JavaScript, CSS, Pretendard 폰트, 상단 로고와 아이콘을 포함하므로 개발 서버 없이 열 수 있습니다. 콘텐츠 이미지·광고 GIF는 기존 외부 URL을 유지하므로 인터넷 연결이 필요합니다. 상담 폼과 Meta Pixel도 기존 외부 서비스입니다.
